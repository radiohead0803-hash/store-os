# 전자상거래 법률 준수 체크리스트

## 🚨 필수: 사업 시작 전

### 1. 사업자 등록 (무료)
- [ ] 관할 세무서 방문 또는 홈택스 온라인 신청
- [ ] 사업자 유형: 간이과세자 (연 매출 8,000만원 미만) 또는 일반과세자
- [ ] 업종: 전자상거래업
- [ ] 소요 시간: 즉시 발급
- [ ] **미등록 시**: 무등록 영업 → 과태료 + 세금 가산세

### 2. 통신판매업 신고 (무료)
- [ ] 정부24 (www.gov.kr) 온라인 신청
- [ ] 필요 서류: 사업자등록증, 신분증
- [ ] 소요 시간: 2-3일
- [ ] 신고번호 발급 → 웹사이트에 표시 필수
- [ ] **미신고 시**: 2년 이하 징역 또는 5,000만원 이하 벌금

### 3. 이용약관 작성 (무료)
- [ ] 공정거래위원회 표준약관 활용 (www.ftc.go.kr)
- [ ] 필수 포함 사항:
  - 환불/교환/반품 정책
  - 개인정보 수집 및 이용
  - 분쟁 해결 절차
  - 사업자 정보
- [ ] 웹사이트에 명확히 게시

## 💸 환불/교환 정책 (전자상거래법)

### 청약철회권 (7일)

**소비자 권리**:
- 상품 수령 후 7일 이내 환불 가능
- 단순 변심도 가능
- 환불 비용: 소비자 부담 (배송비)

**예외 사유 (환불 불가)**:
- 포장 개봉으로 가치 현저히 감소 (화장품, 식품)
- 디지털 상품: 다운로드 또는 사용 시작 시
- 맞춤 제작 상품
- 시간 경과로 재판매 곤란 (신선식품)

### 명시 방법

```markdown
## 환불/교환 정책

### 반품 가능 기간
- 상품 수령 후 7일 이내

### 반품 비용
- 단순 변심: 고객 부담 (왕복 배송비)
- 상품 하자: 판매자 부담

### 반품 불가 사유
- 포장 개봉 및 사용 흔적 (위생 상품)
- 디지털 파일 다운로드 완료 시
- 고객 귀책 사유로 상품 훼손

### 환불 처리 기간
- 반품 확인 후 3영업일 이내

### 문의
- 이메일: refund@example.com
- 전화: 02-1234-5678 (평일 9-18시)
```
