# First Sticker Slice

## Goal

Launch the first reward-sticker product through the self-owned AI-operated store MVP.

## First Product

- Product: 초등 저학년 칭찬스티커판 + 칭찬스티커 세트
- Target: 초등학교 1-3학년 자녀를 둔 엄마
- Promise: 잔소리 대신 체크와 칭찬으로 생활습관을 관리
- Initial quantity: 20-30 sets
- Price test: 6,900-9,900 KRW

## MVP Flow

1. AI generates product idea.
2. AI scores it and recommends it.
3. Operator approves the first product.
4. Claude Design creates assets.
5. AI generates listing draft and FAQ.
6. Proof Agent checks print readability, copyright, claims, and product clarity.
7. Operator approves publication.
8. Customer orders through the public page.
9. Inventory decreases.
10. AI suggests reorder if stock is low.
11. CS Agent drafts replies and auto-replies only to approved low-risk FAQs.
12. Analytics Agent recommends changes.

## Product Proof Checklist

- A4 print legibility checked.
- Sticker cutline quality checked.
- No unauthorized character/icon/font risk.
- Product components clear.
- Refund and delivery notes approved.
- Product page preview captured.
- Order test captured.
- Inventory deduction tested.
- Low-risk CS response tested.

## Starter Listing Sections

1. Problem hook
2. What is included
3. How to use
4. Recommended for
5. Size/material/printing notes
6. Delivery/refund notice
7. FAQ
8. Review request note
