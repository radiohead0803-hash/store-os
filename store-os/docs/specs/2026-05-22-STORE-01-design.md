## 2. 제품 SKU 구조

| SKU | 가격 | 구성 | 비고 |
|---|---|---|---|
| `STORE-01-STD` | 9,900원 | 보드판(표준 디자인) + 칭찬스티커 1세트 (30매) | 50건 인쇄 발주 |
| `STORE-01-CUSTOM` | 11,900원 | 보드판(자녀 이름 인쇄) + 칭찬스티커 1세트 (30매) | 주문 시 자가 인쇄 또는 추가 발주 |

- 두 SKU의 보드판 베이스 디자인은 동일. 차이는 자녀 이름 인쇄 영역만.
- 칭찬스티커 세트는 두 SKU 동일.
- 50건 발주는 표준 디자인만. CUSTOM은 주문 발생 시 처리.

### 보드판 사양
- **사이즈**: A4 (210×297mm)
- **용지**: 250–300g 매트 코팅지
- **레이아웃**: 5×6 = 30칸 스티커 자리 + 상단 자녀 이름 영역 (STD 빈칸 / CUSTOM 인쇄) + 하단 "이번 달 목표" 빈칸
- **색감**: 파스텔톤 1–2색 포인트

### 스티커 세트 (30매 1세트)
- **메시지 분포**: 행동 기반 10매 + 일반 칭찬 10매 + 자유(이모지·도형) 10매
- **사이즈**: 30×30mm
- **재질**: A4 스티커 시트 다이컷 또는 키스컷

## 3. 출시 일정 (14일)

```
Day 1     Canva에서 보드판 + 스티커 디자인 v1
Day 2     v1 자가 출력 1장 검수 + PDF/CMYK 변환
Day 3     인쇄소 견적 3곳 비교 + 컬러프루프 1장 요청
Day 4     인쇄소 50건 발주 (납기 3–5일)
Day 5–6   스마트스토어 상품 등록 페이지 작성
          · auto_claude.py 설명 초안 → legal_check.py 통과 → 운영자 편집
          · 사업자 정보·환불 정책·배송 안내 명시
          · 상품 사진 5장 (디자인 출력본 촬영)
Day 7     마케팅 콘텐츠 시드 (블로그·인스타 2편)
Day 8     인쇄물 입고 → 운영자 자가 품질 검수 (1건 직접 사용 + 사진)
Day 9     상품 페이지 unpublished → public 전환 (운영자 승인 후)
Day 10    지인 베타 1–2명에게 무료·원가 제공 → 후기·사진 자산 확보
Day 11    맘 카페·SNS 콘텐츠 본격 발행 (베타 자산 활용)
Day 12–14 실 판매 모니터링 + CS 24h SLA + 콘텐츠 추가 발행
```

**Critical path**: Day 1–4 (디자인 → 인쇄 발주). 지연 시 14일 일정 깨짐.
**병렬**: Day 5–7 상품 페이지 + 마케팅 시드 = 인쇄 진행 중 동시 진행.

## 4. 마케팅 콘텐츠 계획

### 플랫폼 우선순위
1. **블로그** (네이버 블로그/티스토리) — 검색 유입 핵심, 정보성 글로 신뢰
2. **인스타그램** — 사진·짧은 영상, 학부모 도달
3. **맘 카페** (맘스홀릭·맘이베베 등) — 정보성 댓글·답변. 직접 홍보 금지 (카페 규정 준수)

### 콘텐츠 시리즈 (5편 시드 + 주 2편 누적)
1. "초등 1학년 아이와 약속 지키기 — 우리 집 시행착오" (블로그+인스타)
2. "잔소리 없이 행동 바꾸기 — 행동 기반 칭찬 30가지" (블로그)
3. "냉장고 칭찬 보드 1주 사용 후기 (베타)" (인스타) — Day 10 베타 자산
4. "초등 자녀 자존감·자기효능감 부모용 가이드" (블로그)
5. "엄마가 직접 만든 칭찬스티커 — 자녀 이름 들어간 보드" (인스타) — CUSTOM SKU 홍보

### 운영 룰
- **법률**: 모든 글 `legal_check.py` 통과. "학습 효과 보장"·"성적 향상" 금지. "활용 가능"·"습관 형성 도구"만 사용.
- **이미지**: 실제 사용 사진 우선. AI 이미지 사용 시 IP precheck 통과.
- **링크**: 콘텐츠 끝 1회 자연스럽게. 도배 금지.
- **맘 카페**: 직접 홍보 금지, 정보성 답변만. 프로필에 스토어 표시.

### KPI 추적 (Day 9부터)
- 블로그 일 방문자
- 인스타 도달·저장
- 스토어 유입 출처 (검색 / 블로그 / 인스타 / 직접)
- **목표 미달 트리거**: Day 14 매출 0건 → 콘텐츠 형식·키워드 재검토 (광고 도입은 보류)

## 5. 운영 워크플로 (주문 → 발송 → CS)

### 주문 수신 → 발송 (24시간 SLA)

```
주문 접수 (스마트스토어)
   ↓ 운영자 확인 (일 2회: 오전·저녁)
[STD?]
   ├─ YES → 재고 1건 픽업 → 송장 → 포장 → 발송
   └─ NO  → CUSTOM → 자녀 이름 확인 → 자가 인쇄 1매 → 포장 → 발송
   ↓
배송 추적 번호 입력 → 자동 톡톡 안내
   ↓
D+3 후기 요청 톡톡 (운영자 수동 1회)
```

### CS 분류 + 처리

| 카테고리 | 처리 | 자동화 레벨 |
|---|---|---|
| 단순 문의 (배송·재고·사용법) | 톡톡 24h, FAQ 템플릿 5개 | L1 (수동) |
| 환불·교환 | 7일 미개봉 즉시 승인 / 개봉 운영자 판단 | **L0** |
| 품질 불만 | 사진 요청 → 인쇄 불량이면 무료 교환 + 사과 | **L0** |
| CUSTOM 이름 오기 | 운영자 100% 책임. 무료 재발송 | **L0** |
| 분쟁·법률 위협 | 즉시 운영자 핸들링. AI·자동 응답 금지 | **L0** |

### 재고 관리
- **위치**: 운영자 자택 (박스 1–2개)
- **추적**: 스마트스토어 기본 차감 + 엑셀 1장 (발주일·입고일·판매일)
- **재발주 트리거**: 잔여 15건 도달 시 검토 (졸업 여부 분기)

### 매일 운영자 체크리스트 (5–10분)
- 신규 주문 확인 + 발송 처리
- 톡톡 메시지 확인 (24h SLA)
- 배송 완료 건 후기 요청 (D+3)
- 재고 잔여 확인
- KPI 1줄 기록 (판매·리뷰·문의·환불)

## 6. 검증·졸업 추적

### Mini 졸업 조건 7개

| # | 항목 | 측정 방법 | 목표 |
|---|---|---|---|
| 1 | 실 판매 건수 | 스마트스토어 통계 (지인 베타 제외) | **10건+** |
| 2 | 긍정 리뷰 | 네이버 리뷰 4점+ | **3건+** |
| 3 | 재구매/문의 | 톡톡 또는 동일 고객 재주문 | **1건+** |
| 4 | 순이익 | 매출 − (인쇄·재료·배송·수수료·포장) | **> 0** |
| 5 | 법률 점검 | `legal_check.py` 필수 조치 0 | 100% |
| 6 | 자가 품질 검수 | Day 8 운영자 직접 사용 + 사진·메모 | 통과 |
| 7 | audit log | 모든 운영 행동 기록 | 누락 0 |

### 졸업 결정 흐름 (Day 14 + 매주)

```

   ↓

   │        → [STORE-04] Mini→Standard 졸업 GOAL 진입
   │
   └─ NO  → 미충족 분석:

            · 순이익 < 0 → 가격·인쇄·물류비 재계산
            · 5/6/7 미달 → 즉시 보강
            → 2주 추가 시도 → 재평가
```

### Auto-pause 트리거

상품 등록 즉시 일시정지 + 운영자 알림:
- 환불·교환률 > 20% (10건+ / 50건)
- 리뷰 평점 < 3.5점 (3건 이상)
- CS 시간당 > 5건
- 법률·분쟁 문의 1건+

## 8. 자동화 경계 (L0–L3)

이번 spec에서는 **L2·L3 자동화 일체 없음.** Standard 진입 후 추가.

| 작업 | 레벨 | 처리 |
|---|---|---|
| 사업자 등록·통신판매업 신고 | L0 | 운영자 직접 (이미 완료) |
| 약관·환불 정책 작성 승인 | L0 | AI 초안 → 운영자 검토·승인 |
| 보드판·스티커 디자인 (Canva) | L1 | 운영자 직접 작업 |
| 상품 설명 카피 | L1 | Claude 초안 → 편집 → `legal_check.py` → 등록 |
| 가격·재고 설정 | L1 | 운영자 직접 |
| 인쇄 발주 | L0 | 운영자 직접 |
| 상품 등록 | L1 | 운영자 직접 (Mini는 API 미사용) |
| 발송 | L0 | 운영자 직접 |
| CS 응답 (단순) | L1 | 운영자 직접, FAQ 템플릿 참고 |
| CS 응답 (환불·법률·분쟁) | L0 | 운영자 직접 (AI 자동 응답 금지) |
| 마케팅 콘텐츠 발행 | L1 | 운영자 작성·편집·발행 |
