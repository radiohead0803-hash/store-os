# Claude Design Prompt — STORE-01 보드판 v1

> [claude-design-automation.md](../../../../references/claude-design-automation.md) §프롬프트 10요소 적용.

## 1. 제품명 + 타겟

- 제품: 초등 저학년 칭찬스티커 보드판 (STORE-01-STD / STORE-01-CUSTOM)
- 타겟: 초등 1–3학년 자녀를 둔 학부모

## 2. 자산 종류 + 크기

- A4 세로 PDF (인쇄용) — 본 환경 출력은 SVG, 운영자가 Day 2에 PDF/CMYK 변환
- 210 × 297 mm
- CMYK 인쇄용 (sRGB 출력 → CMYK 변환 단계 별도)

## 3. 사용 장면

- 가정 냉장고 또는 아이 방 벽에 부착
- 한 달 단위 사용 (30칸 = 약 30일 매칭)
- 자녀가 행동·약속을 지키면 스티커 1매 부착

## 4. 스타일 제약

- 파스텔 색감 1–2색 포인트 (메인: 민트 #A8DADC, 보조: 소프트 핑크 #FFD6E0)
- 배경: 흰색
- 미니멀, 어린이 친화
- 글자체: 라운드 산세리프 (예: Pretendard·SD 산돌고딕 라이트)

## 5. 포함할 텍스트

- 상단 좌측: `이름: __________` (STD는 빈 줄, CUSTOM은 자녀 이름 인쇄)
- 중앙 그리드: 5열 × 6행 = 30칸 (각 30×30mm, 칸 간 2mm)
- 하단: `이번 달 목표: __________` (보호자 수기 작성 영역)

## 6. 인쇄 제약

- CMYK, 300dpi 인쇄 가정
- Bleed 3mm (vendor 템플릿에 따라 조정)
- Safe area 5mm (텍스트·중요 요소는 가장자리에서 5mm 이상 안쪽)
- 종이: 250–300g 매트 코팅지

## 7. 접근성·가독성 제약

- 초등학생(키 110cm) 1m 거리에서 "이름: ___" 가독
- 학부모 30cm 거리에서 모든 텍스트 가독
- 색약 친화 (민트·핑크 둘 다 색약자도 구분 가능한 명도 차)

## 8. 회피할 것

- 캐릭터·로고·저작권 일러스트 0
- "학습 효과 보장", "성적 향상", "100% 효과" 같은 단정 표현
- 미세 글씨 (10pt 미만)
- 어두운 톤·고채도 (어린이 친화 안 됨)

## 9. 필수 export

- PDF (CMYK 인쇄용) — Day 2 변환
- 본 환경 출력: SVG (`board-v1.svg`)
- 추가: PNG 썸네일 (Day 2 변환 시 함께)

## 10. proof 체크리스트 (Day 2 자가 검수에서 사용)

- [ ] A4 출력 시 글자 모두 가독
- [ ] 30칸 그리드 정렬 (칸 간격 2mm 균일)
- [ ] 색감 sRGB → CMYK 변환에서 변색 허용 범위
- [ ] 저작권·상표 0 (IP precheck)
- [ ] 단정·과대광고 표현 0 (`legal_check.py`)
- [ ] 자녀 이름 영역(상단) + 목표 영역(하단) 손글씨 충분한 공간
