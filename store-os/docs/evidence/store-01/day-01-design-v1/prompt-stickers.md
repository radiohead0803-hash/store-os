# Claude Design Prompt — STORE-01 스티커 시트 v1

> [claude-design-automation.md](../../../../references/claude-design-automation.md) §프롬프트 10요소 적용.

## 1. 제품명 + 타겟

- 제품: 칭찬스티커 시트 (보드판 매칭, STORE-01-STD/CUSTOM 공통)
- 타겟: 초등 1–3학년 자녀를 둔 학부모

## 2. 자산 종류 + 크기

- A4 다이컷 (또는 키스컷) 스티커 시트
- 210 × 297 mm (시트), 각 스티커 30 × 30 mm
- 30매 (6열 × 5행)
- 본 환경 출력: SVG, 운영자가 Day 2에 PDF/CMYK 변환 + vendor 다이컷 가이드 적용

## 3. 사용 장면

- 보드판(`board-v1.svg`)의 30칸에 부착
- 한 달치 (30일) 행동·칭찬 마킹
- 떼었다 다시 붙이기 가능 (재부착성)

## 4. 스타일 제약

- 보드판과 동일 파스텔 톤 (민트 #A8DADC, 소프트 핑크 #FFD6E0)
- 메시지별 배경 변형: 행동 기반(민트), 일반 칭찬(핑크), 자유(노랑 #FFF3B0)
- 라운드 산세리프, 굵기 600

## 6. 인쇄 제약

- CMYK, 300dpi
- vendor 다이컷 또는 키스컷 템플릿 적용
- Cutline: 각 스티커 외곽 0.25mm 처리
- Safe area: cutline에서 3mm 이상 안쪽에 텍스트
- 시트 재질: 매트 비닐 또는 종이 스티커, 재부착 가능 약접착

## 7. 접근성·가독성 제약

- 30×30mm 안에서 모든 텍스트 가독 (어린이 눈높이 30cm 거리)
- 8글자(예: "스스로 정리했어요") 시 폰트 약 3.5pt
- 짧은 메시지("잘했어요") 시 폰트 약 5pt

## 8. 회피할 것

- 저작권 캐릭터·연예인 일러스트 0
- 미세 글씨 (cutline 안쪽 3mm 안전 영역 침범 금지)
- "성적 향상", "100% 효과" 같은 단정 표현
- 어두운 톤 (어린이 친화 안 됨)

## 9. 필수 export

- PDF (CMYK 인쇄용 + 다이컷 가이드 라인) — Day 2 변환
- 본 환경 출력: SVG (`stickers-v1.svg`)
