## 가격 변동 리스크

- **모델 가격 변동**: Anthropic·OpenAI 가격은 변동. 분기마다 cost_calculator.py 재실행.
- **트래픽 spike**: 광고 출시·바이럴 시 인프라 비용 단기 급증. Vercel/Railway 모두 사용량 기반.
- **이미지 생성 비용**: 디자인 iteration 횟수에 따라 ×3까지 가능. 운영자 한도 설정 필수.

## 손익분기 한 줄 정리

| 단계 | 손익분기 매출 | 권장 단가 (3% 마진 기준) |
|---|---|---|
| Mini | 0원 | — (제품 단가 마진이 양수면 OK) |
| Standard | 월 50만원 | 8,000–15,000원 |
| Full | 월 400만원 | 10,000–30,000원 (또는 묶음판매) |

월 매출이 손익분기의 2배 이하인 단계는 다음 단계로 가지 않는다. 도구 비용이 매출보다 빨리 늘면 망한다.

## 비용 시뮬레이션 — 직접 돌려보기

```bash
python scripts/cost_calculator.py \
  --monthly-products 100 \
  --monthly-orders 300 \
  --monthly-cs-tickets 50
```

값을 자신의 운영 규모로 바꿔 본인 단계의 손익을 검증한다.
